# 🚀 InterviewAI - Advanced AI Technical Interview Platform

**InterviewAI** is a production-grade, full-stack platform designed to help developers ace their technical interviews. It features a real-time AI interviewer, an automated resume analyzer, and a comprehensive DSA preparation suite.

## ✨ Key Features

### 🎙️ AI Mock Interview Engine
- **Real-time Conversational AI:** Practice with a "Senior Full-Stack Interviewer" persona.
- **Voice Recognition:** Speak your answers naturally using built-in speech-to-text.
- **AI Voice Feedback:** The interviewer responds with human-like voice synthesis.
- **Hardware Control:** Manual camera/microphone toggles with full OS hardware release for privacy.

### 📄 Resume AI Analyzer (ATS)
- **Instant ATS Scoring:** Upload your resume and get an instant score out of 100.
- **Skill Extraction:** AI automatically identifies your core strengths.
- **Gap Analysis:** Identifies missing keywords and suggested improvements for top tech roles.

### 💻 DSA & Coding Hub
- **Topic-Wise Questions:** Master Data Structures and Algorithms with a curated list of top 150 patterns.
- **Integrated Code Editor:** Solve problems directly within the platform.
- **Progress Tracking:** Monitor your solved questions and difficulty distribution.

### 🏆 Gamified Experience
- **Global Leaderboard:** Compete with developers worldwide for the top rank.
- **Detailed Profile:** Track your streaks, accuracy, and recent interview activity.
- **Responsive Layout:** Optimized for a full-screen, high-performance desktop experience.

## 🚀 Getting Started

### Prerequisites
- JDK 17 or higher
- Node.js & npm
- MySQL Server

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/1999NITISH/InterviewAI.git
   cd InterviewAI
   ```

2. **Backend Setup:**
   - Configure your database in `backend/src/main/resources/application.properties`.
   - Run the Spring Boot application:
     ```bash
     cd backend
     ./mvnw spring-boot:run
     ```

3. **Frontend Setup:**
   ```bash
   cd frontend
   npm install
   npm run dev
   ```

## 🛡️ Privacy & Safety
The platform requests camera and microphone permissions only during active interview sessions. Users have manual "Kill Switch" control to ensure hardware is fully released when not in use.
